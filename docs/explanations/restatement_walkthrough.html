Nothing is ever deleted: landing files, bronze and slv_sales_conformed are append-only, and the late row stays in quarantine with its status changed. Totals are never edited by hand: the daily summary and every view are recalculated from the line-level fact. The version table keeps every value each day has had, so any figure "as reported on" a date can be rebuilt. Run make demo-restatement to see the same flow on the PoC data.
